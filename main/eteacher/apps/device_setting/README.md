
在eteacher/apps/device_setting文件夹中编写device_setting.cc代码实现系统设置功能：
1. 充分利用eteacher\app_manager和eteacher\app_service文件夹下资源，该app有上栏和下栏，上栏和下栏之间部分为app工作区；
2. app页面中全部用app_ui库中的控件实现；上栏和下栏用ui_status.cc实现
3. 该app工作区包括菜单，列表，软键盘等控件；app工作区最上面是菜单，下面为显示选中的菜单内容；
4. 菜单包含WIFI设置，语言设置，用户设置，学习偏好，设备信息一级菜单，WIFI设置里二级菜单为添加网络和已保存网络；通过左右可以切换一级菜单，有二级菜单的选项，显示二级菜单，通过导航键可以进入一级菜单和二级菜单，当按C键进入该页面，B键退出该页面返回菜单一级菜单，选中的菜单项黑底白字，未选中的菜单项白底黑字；
5. 如果进入二级菜单添加网络时，对项目WIFI进行配置功能；提供按钮控件，开始扫描，把扫描结果在列表控件中显示出来，通过软键盘控件实现密码输入，当密码输入完毕后，按C键开始连接网络，如果连接成功则在右侧显示当前已经连接的网络，如果连接失败，在左侧提示错误；；
6. 如果进入二级菜单已保存网络时，在列表空间里显示已保存WIFI列表；
