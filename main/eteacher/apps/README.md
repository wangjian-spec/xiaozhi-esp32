###### 按键的全局定义：
1. 音量只用于调节音量
2. 上下左右导航键只用于选择
3. select用于退出app，start用于进入app
4. tabview中左右切换选项，上下选择菜单和进行焦点切换，有焦点的控件白底黑字，无焦点的控件白底黑字，B键返回上级菜单，C键进入菜单；
4. app中的菜单，上下键切换菜单项，C或start进入菜单项，B返回到上级菜单；
4. 对于有语音输入或者输出功能的app，start键录音，A键播放
5. 软键盘，B退格，C键确认字符输入，D翻页,start确认完整输入
